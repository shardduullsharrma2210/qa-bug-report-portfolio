# Full Name Field Accepts a Single Character

## Summary
The Full Name field allows the user to register an account using only a single character.

## Steps to Reproduce
1. Open the registration page.
2. Enter `A` in the Full Name field.
3. Fill in the remaining required fields with valid data.
4. Submit the registration form.

## Current Behaviour
The registration is successfully completed with `A` entered as the Full Name.

## Expected Result
The Full Name field should require a valid full name and should not accept a single character.

## Severity
Medium

## Priority
Medium
